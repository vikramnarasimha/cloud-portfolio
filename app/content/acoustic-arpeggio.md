Introduction to Data Engineering talks about the role of the Data Engineer, which is to build data pipelines. 

What really is a data pipeline. 

In google terminology , the data pipeline is described as comprising of 4 stages

1. Replicate / Migrate
2. Ingest
3. Transform 
4. Store

Replicate / Migrate phase is all about using the right tools to migrate data to google cloud based on 
data size and network bandwidth - the key factors in making the decision. The tools / services available
for migrating data into Google cloud are
- gcloud storage cp 
- Storage transfer service
- Transfer appliance
- Data Streams
